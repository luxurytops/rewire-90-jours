## 1. Version corrigee

Le projet "Atelier Pratique IA 2H - De 0 a votre premier produit IA" vise a aider des professionnels non techniciens a transformer une idee en premiere offre structuree.

L'atelier s'adresse aux entrepreneurs, coachs, consultants, formateurs, commercants, independants, salaries en reconversion et porteurs de projet qui souhaitent utiliser l'IA de maniere concrete.

Le besoin principal est clair : ces publics ont souvent des idees, mais manquent de methode pour les clarifier, les structurer et les transformer en supports commerciaux testables.

L'objectif est de proposer un atelier pratique de deux heures permettant de produire des premieres versions de livrables : analyse simple du marche, offre structuree, page de vente, message WhatsApp, base de publicite Meta et plan d'action sur 7 jours.

## 2. Points a verifier par l'humain

- Le public prioritaire est-il le marche marocain ou un public francophone plus large ?
- Le prix indicatif de l'offre doit-il etre defini maintenant ?
- Le format presentiel, distanciel ou hybride doit-il etre priorise ?
- Les supports commerciaux seront-ils testes avec des prospects reels ?
- La promesse "premier produit IA" doit-elle etre precisee pour eviter toute exageration ?

## 3. Checklist finale

- [x] Sujet clair.

- [x] Objectif concret.
- [x] Resultat attendu visible.
- [x] Premiere action faisable.
