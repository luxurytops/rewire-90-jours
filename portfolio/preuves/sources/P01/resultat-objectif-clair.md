# Resultat prompt - Objectif clair

Prompt execute : `../prompts/prompts-seance-02.md`

Source utilisee : `../../../02-documents/note-cadrage-courte.md`

Statut : V1 - A RELIRE

## Point de depart

Le projet part d'un besoin observe : beaucoup d'entrepreneurs, coachs, consultants, formateurs et porteurs de projet ont des idees, mais manquent de methode pour les transformer rapidement en offres claires et testables.

Mohamed BOUMRAH souhaite utiliser son experience de Master coach personnel et professionnel pour proposer un atelier pratique de 2 heures, appuye par l'intelligence artificielle, sous la structure DEEP PERFORMANCE - REWIRE YOUR MIND.

## Productions visees

L'objectif est de construire un atelier operationnel permettant aux participants de produire les premieres bases de leur offre :

- clarification de l'idee ;
- identification du public cible ;
- proposition de valeur ;
- premiere offre commerciale ;
- page de vente ;
- message WhatsApp commercial ;
- base de publicite Meta ;
- plan d'action sur 7 jours.

## Preuves attendues

Les preuves attendues doivent montrer que le projet avance de maniere concrete :

- note de cadrage finalisee ;
- fiche projet V1 ;
- supports de l'atelier ;
- page de vente V1 ;
- messages commerciaux relus ;
- plan d'action testable ;
- retours humains apres test.

## Trois premiers livrables

1. Fiche projet V1 de l'atelier pratique IA 2H.
2. Page de vente de l'atelier.
3. Kit de test commercial : message WhatsApp, base Meta et plan d'action 7 jours.

## Version courte de l'objectif

Pendant le Challenge 100 jours, je veux transformer mon idee d'atelier IA 2H en offre claire, testable et commercialisable, avec des livrables concrets, verifies humainement et classes dans mon portfolio.
