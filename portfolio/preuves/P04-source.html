# Note de cadrage courte

## Sujet

Concevoir un atelier pratique IA de 2 heures pour aider des entrepreneurs, coachs, consultants, formateurs, commercants et porteurs de projet a passer d'une idee a une premiere offre structuree.

## Public concerne

Le public concerne regroupe des professionnels non techniciens qui veulent utiliser l'intelligence artificielle de maniere concrete :

- entrepreneurs ;
- coachs ;
- consultants ;
- formateurs ;
- commercants ;
- independants ;
- porteurs de projet ;
- salaries en reconversion.

## Probleme ou besoin

Beaucoup de professionnels ont des idees interessantes, mais manquent de methode pour les transformer en offres claires, visibles et testables.

Ils ont besoin d'un cadre simple pour clarifier leur idee, comprendre leur public, construire une proposition de valeur et preparer des supports commerciaux.

## Objectif du document

Cette note sert a cadrer l'atelier avant de produire les supports suivants : fiche projet, page de vente, message WhatsApp, base de publicite Meta et plan d'action 7 jours.

## Resultat attendu

A la fin de l'atelier, chaque participant doit repartir avec une premiere version exploitable de son offre, des supports de communication a tester et une feuille de route simple.

## Premiere action

Transformer cette note de cadrage en fiche projet V1, puis verifier les informations manquantes avant de produire la page de vente.

# Fiche projet V1

## Nom du projet

Atelier Pratique IA 2H - De 0 a votre premier produit IA.

## Objectif

Concevoir un atelier pratique de deux heures permettant a des professionnels non techniciens de transformer une idee en premiere offre structuree et testable grace a l'intelligence artificielle.

## Public cible

Entrepreneurs, coachs, consultants, formateurs, commercants, independants, salaries en reconversion et porteurs de projet.

## Probleme traite

Le public a souvent des idees, mais manque de methode pour clarifier le projet, identifier le public cible, structurer une offre et produire des supports commerciaux.

## Solution proposee

Un atelier pratique et guide, combine a des prompts IA, permettant de produire des livrables concrets en deux heures.

## Livrables attendus

- Analyse simple du marche.
- Offre structuree.
- Prompt personnel.
- Page de vente.
- Message WhatsApp.
- Base de publicite Meta.
- Plan d'action 7 jours.

## Outils utiles

- Note de cadrage.
- Prompts structures.
- Assistant IA.
- VS Code ou editeur Markdown.
- Checklist de controle humain.

## Etapes de production

1. Finaliser la note de cadrage.
2. Produire la fiche projet V1.
3. Rediger la page de vente V1.
4. Creer le message WhatsApp commercial.
5. Preparer la base de publicite Meta.
6. Rediger le plan d'action 7 jours.
7. Tester avec un premier public.

## Criteres de reussite

- Le public comprend la promesse de l'atelier.
- Les livrables sont concrets.
- Le format de 2 heures reste realiste.
- Les supports sont prets a etre testes.
- Les promesses restent prudentes.

## Risques ou limites

- Promesse trop large.
- Trop de livrables pour 2 heures.
- Public cible trop disperse.
- Prix non defini.
- Supports a verifier humainement avant diffusion.

## Prochaine action

Produire le plan du guide pratique de l'atelier.

## Points a verifier par l'humain

- Prix.
- Format exact.
- Nombre de participants.
- Canal de prospection.
- Exemple reel a utiliser.
